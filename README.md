# 🏥 Personal Health Assistant

A full-stack, AI-powered personal health management platform that creates a **personalized wellness plan** for every user. Built with a modern three-tier architecture: React frontend, Node.js/Express backend, and a Python AI microservice — all connected to a shared MongoDB Atlas database and powered by **Google Gemini** and **Groq LLaMA** language models.

## 🏗️ Architecture Overview

```
┌─────────────────────────────────────────────────────────────────┐
│                        User's Browser                          │
│                    React (Vite) Frontend                        │
│                      localhost:5173                             │
└──────────────────────────┬──────────────────────────────────────┘
                           │ REST API calls
          ┌────────────────┴────────────────────┐
          │                                     │
          ▼                                     ▼
┌─────────────────────┐             ┌───────────────────────┐
│  Node.js / Express  │             │  Python FastAPI        │
│  Backend API        │────────────▶│  AI Microservice       │
│  localhost:5000     │  HTTP proxy │  localhost:8000        │
└─────────┬───────────┘             └───────────┬───────────┘
          │                                     │
          │  Mongoose ODM                       │  google-generativeai
          ▼                                     │  langchain-google-genai
┌─────────────────────┐                         │
│   MongoDB Atlas     │                         ▼
│   (Cloud DB)        │             ┌───────────────────────┐
└─────────────────────┘             │  Gemini / Groq APIs   │
                                    └───────────────────────┘
```

- The **Node.js backend** handles all authentication, data persistence, and acts as a proxy to the AI microservice.
- The **Python FastAPI microservice** handles all AI-heavy tasks: recipe generation (with LangChain graph), question generation, and streaming.
- The **frontend** communicates exclusively with the Node.js backend.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed:

| Tool | Version | Notes |
|---|---|---|
| Node.js | ≥ 18.x | For backend & frontend |
| npm | ≥ 9.x | Package manager |
| Python | ≥ 3.10 | For AI microservice |
| pip | latest | Python package manager |
| MongoDB Atlas | — | Free tier sufficient |

### Environment Variables

Create a `.env` file inside the `backend/` directory:

```env
# ── Database ──────────────────────────────────────────
MONGO_URI=mongodb+srv://<username>:<password>@cluster.mongodb.net/<dbname>

# ── Authentication ────────────────────────────────────
JWT_SECRET=your_super_secret_jwt_key_here

# ── Email (for OTP / forgot password) ────────────────
EMAIL_USER=your_gmail_address@gmail.com
EMAIL_PASS=your_gmail_app_password

# ── AI APIs ───────────────────────────────────────────
GROQ_API_KEY=your_groq_api_key_here
GEMINI_API_KEY=your_google_gemini_api_key_here
```

Create a `.env` file inside the `Ai-tasks/` directory:

```env
GEMINI_API_KEY=your_google_gemini_api_key_here
```

> **Note:** Never commit `.env` files to Git. They are already listed in `.gitignore`.

### Installation

#### 1. Clone the repository

```bash
git clone <your-repo-url>
cd Personal-health-assitant-
```

#### 2. Install frontend dependencies

```bash
cd frontend
npm install
```

#### 3. Install backend dependencies

```bash
cd ../backend
npm install
```

#### 4. Install Python AI microservice dependencies

```bash
cd ../Ai-tasks
pip install fastapi uvicorn python-dotenv google-generativeai langchain langchain-google-genai langgraph
```

### Running the App

Open **three separate terminals**:

**Terminal 1 — Frontend**
```bash
cd frontend
npm run dev
# Runs at http://localhost:5173
```

**Terminal 2 — Node.js Backend**
```bash
cd backend
node index.js
# Runs at http://localhost:5000
```

**Terminal 3 — Python AI Microservice**
```bash
cd Ai-tasks
uvicorn app:app --reload --port 8000
# Runs at http://localhost:8000
```

## 📡 API Reference

### Auth Routes

**Base:** `http://localhost:5000/api/auth`

| Method | Endpoint | Description | Auth Required |
|---|---|---|---|
| `POST` | `/register` | Register new user | ❌ |
| `POST` | `/login` | Login, returns JWT | ❌ |
| `POST` | `/send-otp` | Send OTP to email for password reset | ❌ |
| `POST` | `/verify-otp` | Verify OTP code | ❌ |
| `POST` | `/reset-password` | Reset password after OTP verification | ❌ |

**Register Request Body:**
```json
{
  "fullname": "John Doe",
  "email": "john@example.com",
  "password": "securepassword123"
}
```

**Login Response:**
```json
{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "user": { "id": "...", "fullname": "John Doe", "email": "..." }
}
```

### AI Microservice (FastAPI)

**Base:** `http://localhost:8000`

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/` | Health check (`{"status": "AI Backend Running"}`) |
| `POST` | `/questions/generate` | Generate 10 personalized health questions |
| `POST` | `/recipe/generate` | Generate a recipe (supports food image upload) |
| `POST` | `/recipe/stream` | Streaming recipe generation |

**`POST /questions/generate` Request:**
```json
{
  "healthProfile": {
    "ageGroup": "26-35",
    "gender": "Male",
    "height": 175,
    "weight": 70,
    "primaryGoal": "weight_loss",
    "activityLevel": "moderate",
    "dietType": "vegetarian"
  }
}
```

**`POST /recipe/generate` Request (multipart form):**
```
health_profile: <JSON string of user health profile>
previous_recipes: <JSON array of previous recipe names>
message: "I want something high protein"
image_paths: <optional JSON array of uploaded image file paths>
```

## 🗄️ Database Models

### User Model (`users` collection)
```
User {
  fullname         String (required)
  displayName      String
  avatar           String (URL path)
  email            String (unique, required)
  password         String (bcrypt hashed)
  onboardingCompleted Boolean (default: false)

  healthProfile {
    ageGroup, gender, height, weight
    primaryGoal (enum: weight_loss | weight_gain | maintain_fitness | improve_stamina | better_skin | general_wellness)
    activityLevel (enum: low | moderate | high)
    dietType (enum: vegetarian | vegan | eggetarian | non_vegetarian | mixed)
    allergies, monthlyFoodBudget, sleepHours
    skinType (enum: oily | dry | combination | normal | sensitive)
    waterIntakeLiters
  }

  aiQuestions [{
    question String
    options  [String]
    answer   String   ← comma-separated if multiple selections
  }]

  totalPoints      Number (default: 0)
  currentStreak    Number (default: 0)
  longestStreak    Number (default: 0)
  lastActivityDate String (YYYY-MM-DD)
  timestamps: createdAt, updatedAt
}
```

### DailyActivity Model
```
DailyActivity {
  userId     ObjectId (ref: User)
  date       String (YYYY-MM-DD)
  exercise   { completed: Boolean, notes: String }
  diet       { completed: Boolean, notes: String }
  skinCare   { completed: Boolean, notes: String }
  water      { amount: Number (liters) }
}
```

### Other Models
| Model | Purpose |
|---|---|
| `ExercisePlan` | Stores generated workout plans per user |
| `SkinCarePlan` | Stores generated skincare routines per user |
| `Diet` | Stores generated diet/meal plans per user |

## 🏆 Gamification System

The app includes a points and streak system to motivate healthy habits:

- **Points** are awarded for logging daily activities (exercise, diet, skincare, water).
- **Streaks** track consecutive days with at least one completed habit.
- The **leaderboard** ranks all users by total points.
- Dashboard displays:
  - Current streak 🔥
  - Longest streak (calculated from activity history)
  - Streak calendar (visual month view with habit heatmap)
  - Weekly progress donut chart
